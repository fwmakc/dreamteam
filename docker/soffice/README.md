# Мост LibreOffice для тула `docs`

Конвертация документов: pdf, doc, docx, xls, xlsx, ppt, pptx, odt, ods, odp,
rtf, html, csv, txt — LibreOffice в контейнере, на машине ничего ставить не
нужно. Тул `docs` обращается сюда для форматов, которые Node-пакеты не умеют:
чтение старых `.doc/.xls/.ppt` и запись `.odt/.ods` (а также `convert`-подкоманда).

## Запуск

```
cd docker && docker compose --profile soffice up -d --build
```

Первый старт качает и ставит LibreOffice в образ (~700 МБ) — это один раз.
Проверка:

```
curl http://localhost:8200/health          # {"service":"soffice"}
curl -F file=@договор.docx -F target=pdf http://localhost:8200/convert -o договор.pdf
```

## Настройка в приложении

По умолчанию тул `docs` стучится на `http://127.0.0.1:8200`. Если контейнер
поднят на другой машине, пропишите адрес в карточке тула `docs`
(`~/.dreamteam/agents.json` → `tools.docs.soffice`):

```json
"tools": { "docs": { "soffice": "http://192.168.1.50:8200" } }
```

Порт снаружи меняется в `compose.yaml` (строка `ports: ["8200:8200"]`),
внутри контейнера всегда 8200.

## Детали

- Каждый запрос получает свой профиль пользователя (`-env:UserInstallation`),
  поэтому зависшие/кривые документы не ломают следующие конвертации.
- Конвертации идут по одной (lock в `app.py`): очередь из нескольких файлов
  обработается по порядку; таймаут одного конверта — `SOFFICE_TIMEOUT`
  секунд (по умолчанию 120).
- Шрифты в образе: DejaVu и Liberation (обе с кириллицей; Liberation Sans —
  метрический аналог Arial). Для экзотических шрифтов допишите свои `.ttf`
  через ещё один слой `COPY` в Dockerfile.
- Формат ответа: бинарный файл; ошибка — HTTP 4xx/5xx с текстом по-русски,
  тул `docs` покажет его агенту как есть.
